# Netflix Landing Page Clone

## Project Overview

This project is a responsive Netflix Landing Page Clone built using HTML and CSS. The goal of the project was to recreate the look and feel of Netflix's homepage while developing a deeper understanding of modern web design principles, responsive layouts, and front-end development best practices.

The project focuses on accurately replicating the visual structure of a real-world platform while ensuring that the layout remains responsive and user-friendly across different screen sizes.

---

## Project Objectives

The primary objectives of this project were to:

- Recreate the Netflix landing page design using HTML and CSS.
- Practice building structured and semantic web pages.
- Improve understanding of layout techniques using Flexbox.
- Develop responsive design skills for desktop, tablet, and mobile devices.
- Strengthen CSS styling and positioning techniques.
- Gain experience replicating a professional user interface.

### 1. Planning the Layout

Before coding, I analyzed the Netflix landing page to identify:

- Major sections
- Navigation structure
- Content hierarchy
- Visual spacing
- Layout patterns

This helped create a clear roadmap for development.

### 2. Building the HTML Structure

I created a semantic HTML structure that included:

- Header
- Hero Section
- Feature Sections
- Footer

The goal was to maintain readability and scalability.

### 3. Styling the Interface

Using CSS, I implemented:
